# Life OS v2 — roadmap

Where the v2 work stands between sessions. Each phase gets its own
plan → approval → build cycle: plan on Opus (plan mode), build on Sonnet in a
fresh session. Decisions from the planning interview live in
[`phase-1.md`](phase-1.md) under "Genomen beslissingen" — they bind every phase.

| Phase | Scope | Status |
|---|---|---|
| 1 | Catalog as data, data model v2, migration v1→v2, weighted panel engine, habit CRUD; current UI minimally adapted | **Built** — [`phase-1.md`](phase-1.md) |
| 2 | Renderer: panels + overlays + variant manifest + placeholders; artwork prompt guide | **Built** — [`phase-2.md`](phase-2.md) |
| 3 | Dark editorial design system: tokens, type, grain, base components | Not planned |
| 4 | Onboarding decision tree + profile + Discover/edit | Not planned |
| 5 | Check-in UI (Home) | Not planned |
| 6 | Content layer + gamification: personas, Guide tab, side quests, milestones, badges, XP/level, weekly recap, story card | Not planned |
| 7 | Release-ready: multi-user push, real artwork, copy pass, PWA/iOS check, docs, tester instructions | Not planned |

## How to continue

- **Build a planned phase**: new session, Sonnet — "Read CLAUDE.md and
  docs/plan/phase-N.md and build phase N. Commit per sub-step."
- **Plan the next phase**: new session, Opus in plan mode — "Read
  docs/plan/PLAN.md and plan phase N."
- Update the status column when a phase is built.
